# Call Center Analytics & Machine Learning

## About the Project

This project aims to analyze call center operational data, evaluate operational performance, and make predictions using machine learning methods.

The project involves analyzing data to extract meaningful insights and visualizing the results through charts and an interactive dashboard.

## Project Objectives

- Analyze call center operational performance.
- Examine operational metrics and durations.
- Compare team performance.
- Make analytical results easier to understand through data visualization.
- Perform predictive modeling using machine learning techniques.

## Features

- **Overview:** Displays key performance indicators.
- **Operational Performance:** Analyzes operational metrics.
- **Duration Analysis:** Examines call and process durations.
- **Team Analysis:** Compares team performance.
- **Prediction:** Generates predictions using machine learning.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Flask
- HTML
- CSS
- Bootstrap

## Project Structure

The project consists of data analysis, machine learning, dashboard interface, and data visualization components.

## Note

This project was developed to integrate data analysis and machine learning applications for call center operations.
